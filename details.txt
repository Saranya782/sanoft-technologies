Overview
You are required to design and build a Task Management System that allows organizations to manage
tasks across teams and individual users. The system includes a React-based frontend, a NestJS or
Express.js backend, and is fully deployed on Google Cloud Platform (GCP) using free-tier infrastructure.
Application Description
Core Concept
Build a multi-tenant Organizational Task Management application where:
Administrators can create and manage tasks with defined timings and alert settings.
Users and Admins within the same organization can view tasks and receive time-based alerts.
Tasks can be scoped at three levels: Organization, Team, and Individual User.
Admins (based on user roles) can view reports with date-based filtering and graphical insights into
task completion.
